# 🎡 גלגל המזל של כיתה ה׳

גלגל פרסים שבועי שמבוסס על נקודות קלאס דוג׳ו.

- `index.html` – אפליקציית הילדים (סורקים QR, בוחרים שם, קוד סודי, מסובבים)
- `teacher.html` – מסך המורה (העלאת דוח, מימוש פרסים, פתיחת גלגל, הגדרות, פרסים, QR)
- `backend/Code.gs` – השרת (Google Apps Script). הנתונים נשמרים בגיליון "גלגל המזל – נתונים" ב-Drive של המורה.
- `config.js` – כתובת השרת.

## עדכון השרת
מדביקים את `backend/Code.gs` בפרויקט "גלגל המזל – שרת" ב-script.google.com, שומרים,
ואז פריסה ← ניהול הפריסות ← עריכה ← גרסה חדשה ← פריסה (הכתובת נשארת אותה כתובת).
